# 리뷰 데이터 기반 가설 근거 분석

## 실행
```bash
pip install pandas scipy matplotlib koreanize-matplotlib
python analyze_reviews.py <리뷰 CSV 폴더> [출력 폴더]   # 기본 출력: ./outputs
```
원본 CSV(로보락·삼성/LG 로봇청소기, 샤오미·티피링크 홈캠)는 리포에 포함하지 않았다. 결과 표(`outputs/tables`)와 차트(`outputs/charts`)만 포함.

## 데이터
| 구분 | 리뷰 수 | 반려(`is_pet`) |
|---|---|---|
| 로봇청소기(로보락·LG·삼성) | 11,188 (이벤트 1,252 제외 시 9,936) | 546 (이벤트 제외) |
| 홈캠(샤오미·티피링크) | 4,576 | 296 |

`is_pet`은 리뷰 본문의 반려 키워드 포함 여부(키워드 기반). 평점은 5점이 약 90%라 분석에서 제외.

## 해석 시 주의
- **삼성 털 언급률은 이벤트 리뷰 포함 여부에 따라 33.3% ↔ 17.5%**로 크게 달라진다(반려 리뷰 129 → 57건). 이벤트 리뷰에 반려·털 언급이 많이 섞여 있다는 뜻이므로 기본은 이벤트 제외로 표기했고, 이벤트 포함 결과는 `tables/01_털언급률_청소기.csv`에 같이 있다. 삼성 반려 n=57은 작다.
- 차트 2에서 **털·먼지는 1위가 아니라 2위**(물걸레·얼룩 49% > 털·먼지 45% ≈ 시간 절약 44%)다. 기존 파이 차트(228건, 털 32%)와 분류·건수 기준이 다르므로 팀 합의 사전으로 통일해야 한다. 털 Pain Point의 근거는 "반려 vs 비반려 격차"(차트 1)로 제시하는 편이 더 강하다.
- 이 리뷰들은 **이미 구매한 사람**의 글이라 "구매 고민 중인 미보유 가구"나 "펫 기능이 구매를 앞당긴다"는 직접 증거가 아니다. 직접 구매동기 문장은 반려 546건 중 11건(2%)에 불과했다.
- 홈캠은 제품 각 1종(샤오미 홈캠 3세대, 티피링크 Tapo C210)이라 펫캠 전체를 대표하지 않는다. 홈캠 리뷰에 청소기 언급은 거의 없다.
- 키워드는 정규식이라 오탐·미탐이 있다. 반려 리뷰 100건 정도를 직접 읽어 정밀도를 점검하고 사전을 확정해야 한다.
- 승인형 vs 자동형 선호, 알림 피로, 사분면별 개입, 간식 장치 실현 가능성, 대안 대비 가치 비교는 이 데이터로 검증할 수 없다.
