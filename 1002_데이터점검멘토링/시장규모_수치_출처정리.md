## 2. 못 찾은 수치
- **ThinQ 공식 가입자 수**: 미확인. LG전자 뉴스룸·보도자료에서 확인 필요. (참고: ThinQ 앱 다운로드 1.4억 회 언급이 있으나 가입자 수가 아니고 출처 페이지 불분명 — [LG 뉴스룸](https://www.lg.com/global/newsroom/news/home-appliance-solution/lg-opens-thinq-api-to-foster-smart-home-innovation/))
- **반려가구의 로봇청소기 보유율**: 직접 조사 자료 없음.
- **LG 로봇청소기 정확한 점유율**: 기사에는 "한 자릿수"로만 표기.
- 후보: [한국갤럽 가전 20종 보유율·반려동물 동거율](https://www.gallup.co.kr/gallupdb/reportContent.asp?seqNo=1597) — 로봇청소기 보유율과 반려동물 동거율이 한 조사에 있어 교차 근거가 될 수 있음 (미열람).

## 3. 한계 (발표 시 명시)
- 와이즈앱 수치는 **안드로이드 한정 표본 추정 MAU**이며 가입자 수가 아니다. iOS 이용자가 빠져 있고, 월 1회도 쓰지 않은 가입자도 빠지므로 가입자의 하한선이다.
- 센서타워 수치는 **앱스토어·구글플레이 최초 다운로드 기준 비중**이며 절대 수치가 없다. 연령·페르소나는 미국 기준이다.
- 두 자료는 지표가 달라 서로 섞어 계산하지 않는다. 와이즈앱=국내 이용자 규모, 센서타워=맥락(글로벌 위상, 한국 비중)으로 구분해 쓴다.
